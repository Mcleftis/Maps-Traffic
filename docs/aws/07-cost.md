# 07 — Κόστος

Το κεφάλαιο που καθορίζει αν αυτό το εγχείρημα είναι μάθηση ή λογαριασμός
έκπληξη. Διάβασέ το **πριν** από κάθε deploy.

## Η μόνη διάκριση που μετράει

| Μοντέλο | Χρεώνει | Κίνδυνος |
|---|---|---|
| **Pay-per-use** | Μόνο όταν το χρησιμοποιείς | Χαμηλός — ξεχνάς κάτι, πληρώνεις 0 |
| **Provisioned** | **Ανά ώρα, πάντα** | **Υψηλός** — ξεχνάς κάτι, πληρώνεις μήνες |

Όλα τα bill shock stories είναι από τη δεύτερη κατηγορία. Η λίστα που πρέπει να
ξέρεις απ' έξω:

### 🔴 Χρεώνουν ακόμα κι όταν κοιμάσαι

| Υπηρεσία | Κόστος αν το ξεχάσεις | Ανά μήνα |
|---|---|---|
| **OpenSearch** (t3.small) | ~0.036 $/ώρα | **~26 $** |
| **Global Accelerator** | 0.025 $/ώρα + data | **~26 $** |
| **NAT Gateway** | 0.045 $/ώρα + data | **~35 $** |
| **EKS control plane** | 0.10 $/ώρα | **~72 $** |
| **EMR cluster** (m5.xlarge ×3) | ~0.60 $/ώρα | **~430 $** |
| **Redshift** (ra3.xlplus) | ~1.09 $/ώρα | **~790 $** |
| **RDS/Aurora instance** | ~0.10 $/ώρα+ | **~75 $+** |
| **QuickSight author** | ανά χρήστη | **~18 $** |
| **Shield Advanced** | πάγιο | **3.000 $** |
| **Client VPN endpoint** | 0.10 $/ώρα | **~72 $** |

Ένα ξεχασμένο EMR cluster ένα Σαββατοκύριακο = ~65 $. Ένα ξεχασμένο Redshift
έναν μήνα = ~790 $. Γι' αυτό κάθε 🟡 άσκηση στο [`lab/`](lab/) τελειώνει με
ρητό βήμα **teardown**.

### 🟢 Χρεώνουν μόνο με χρήση

Lambda, API Gateway, S3, DynamoDB on-demand, EventBridge, Step Functions,
Firehose, Athena, Glue jobs, SNS, SQS, CloudWatch Logs, Comprehend, Transcribe,
Rekognition, Batch (μόνο τα instances όσο τρέχουν).

Με τον όγκο αυτού του project, όλα αυτά μαζί: **κάτω από 1 € τον μήνα**.

## Πραγματικός υπολογισμός

Παραδοχές: 50 alerts/ημέρα ≈ 1.500/μήνα, 20 συσκευές που ρωτούν ανά 60″ ≈ 900k
GET/μήνα.

### Φάση 0+1 — ingest + storage

| Υπηρεσία | Χρήση | Κόστος |
|---|---|---|
| API Gateway HTTP | 900k requests | 0.90 $ |
| Lambda (arm64, 512MB, 100ms) | 900k invocations | ~0.10 $ |
| EventBridge | 1.5k events | ~0 $ |
| Step Functions Standard | 1.5k × 8 transitions | ~0.30 $ |
| DynamoDB on-demand | 1.5k writes, 900k reads | ~0.30 $ |
| Firehose | ~5 MB | ~0 $ |
| S3 | ~100 MB | ~0.01 $ |
| CloudWatch Logs | ~500 MB | ~0.25 $ |
| **Σύνολο** | | **~1.90 $/μήνα** |

**Με CloudFront caching των GET** (TTL 60″): τα 900k requests γίνονται ~15k στο
origin. Το κόστος πέφτει κάτω από 0.50 $. Αυτή είναι η μεγαλύτερη μεμονωμένη
βελτιστοποίηση εδώ.

### Φάση 2 — analytics

| Υπηρεσία | Χρήση | Κόστος |
|---|---|---|
| Glue Catalog | <1M αντικείμενα | 0 $ |
| Glue ETL | 30 runs × 3′ × 2 DPU | ~1.30 $ |
| Athena | 30 queries × 100 MB | ~0.02 $ |
| QuickSight author | 1 χρήστης | **18 $** |
| **Σύνολο** | | **~19 $/μήνα** |

Το QuickSight είναι το 95% του κόστους. Εναλλακτικές: Athena API + ένα απλό
HTML dashboard (0 $), ή Grafana σε container.

### Φάση 3 — AI

| Υπηρεσία | Χρήση | Κόστος |
|---|---|---|
| Comprehend | 1.500 × 300 χαρ. | ~0.45 $ |
| Transcribe | 100 × 15″ | ~1.00 $ |
| Rekognition | 200 εικόνες | ~0.20 $ |
| **Σύνολο** | | **~1.65 $/μήνα** |

Φθηνότερο απ' ό,τι περιμένει κανείς. Το ρίσκο εδώ **δεν είναι το κόστος** —
είναι η ακρίβεια στα ελληνικά και η ιδιωτικότητα των φωτογραφιών.

### Φάση 5 — multi-region

| Υπηρεσία | Κόστος |
|---|---|
| Global Accelerator | **26 $** |
| Δεύτερο region (serverless) | ~2 $ |
| DynamoDB Global Tables | ~0.60 $ |
| S3 CRR | ~0.10 $ |
| **Σύνολο** | **~29 $/μήνα** |

Το 90% είναι το Global Accelerator. Με Route 53 failover αντί γι' αυτό: ~3 $.

## Free Tier — τι ισχύει και τι όχι

**Πάντα δωρεάν** (δεν λήγει):

- Lambda: 1M requests + 400k GB-sec/μήνα
- DynamoDB: 25 GB + 25 WCU/RCU
- CloudWatch: 10 μετρικές, 5 GB logs
- SNS: 1M δημοσιεύσεις · SQS: 1M requests
- CloudTrail: πρώτο trail
- Glue Data Catalog: 1M αντικείμενα
- **Access Analyzer: πλήρως δωρεάν**

**12 μήνες μόνο:**

- S3: 5 GB · CloudFront: 1 TB/μήνα · Comprehend: 50k μονάδες
- Transcribe: 60′/μήνα · Rekognition: 5k εικόνες/μήνα

**Ποτέ δωρεάν:** OpenSearch (πέρα από τους 12 μήνες), Redshift (πέρα από 2μηνο
trial), EMR, Global Accelerator, NAT Gateway, EKS control plane.

**Η παγίδα:** το free tier λήγει σιωπηλά στους 12 μήνες. Ό,τι έστησες πέρσι
αρχίζει να χρεώνεται φέτος, χωρίς προειδοποίηση. Το budget alarm είναι η μόνη
άμυνα.

## Έλεγχος κόστους — με σειρά προτεραιότητας

### 1. Budget alarm (πρώτο πράγμα, πριν από κάθε δημιουργία πόρου)

AWS Budgets, μηνιαίο όριο 10 $, ειδοποιήσεις στο 50%/80%/100% **και σε
προβλεπόμενη υπέρβαση**. Το τελευταίο είναι το σημαντικό: σε προειδοποιεί όταν ο
*ρυθμός* δείχνει υπέρβαση, όχι αφού συμβεί.

### 2. SCP περιορισμού regions

Δες [`05-security.md`](05-security.md). Κόβει το «άνοιξα κάτι σε us-east-1 και το
ξέχασα» — που είναι ο πιο συχνός τρόπος να πληρώνει κανείς για πόρους που δεν
θυμάται.

### 3. Cost Anomaly Detection

Δωρεάν. Μαθαίνει το κανονικό σου μοτίβο και ειδοποιεί σε απόκλιση. Πιάνει το
ξεχασμένο cluster πριν γίνει μηνιαίος λογαριασμός.

### 4. Tagging

Κάθε πόρος με `Project=maps-traffic`, `Environment=dev`, `Phase=2`. Χωρίς tags
το Cost Explorer δείχνει «EC2: 47 $» χωρίς να ξέρεις ποιο EC2 και γιατί.

### 5. Teardown ως μέρος της άσκησης

Κάθε 🟡 lab τελειώνει με `sam delete` ή `cdk destroy`. Το βήμα δεν είναι
προαιρετικό — είναι το τελευταίο βήμα της άσκησης.

## Οι βελτιστοποιήσεις με τη μεγαλύτερη απόδοση

Σειρά κατά λόγο *όφελος/προσπάθεια*:

| # | Ενέργεια | Όφελος |
|---|---|---|
| 1 | CloudFront caching στα GET | −95% API/Lambda κόστος |
| 2 | Parquet + partition pruning | −99% Athena κόστος |
| 3 | Graviton (arm64) στη Lambda | −20% |
| 4 | S3 lifecycle → Glacier IR | −68% storage |
| 5 | CloudWatch Logs retention 30 ημερών | −80% logs |
| 6 | DynamoDB TTL αντί για scheduled delete | Δωρεάν διαγραφές |
| 7 | Spot στο Batch | −70% compute |
| 8 | Athena workgroup με scan limit | Αποτρέπει το ατύχημα |

Τα #1 και #2 μαζί κάνουν τη διαφορά ανάμεσα σε «μερικά € τον μήνα» και «μερικά
λεπτά τον μήνα».

## Ο κανόνας

> Κάθε πόρος που δημιουργείς σε lab πρέπει να έχει ημερομηνία λήξης **πριν** τον
> δημιουργήσεις.

Πρακτικά: γράψε στο ημερολόγιό σου «σβήσε το OpenSearch» για την επόμενη μέρα,
**πριν** τρέξεις τη δημιουργία. Όχι μετά.

Ένα ξεχασμένο t3.small OpenSearch cluster κοστίζει 26 $ τον μήνα, επ' αόριστον,
για μια άσκηση 20 λεπτών.
