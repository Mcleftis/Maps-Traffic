# Κοινή χρήση αναφορών μεταξύ συσκευών (relay)

Το Viber επιτρέπει **ένα μόνο κινητό ανά αριθμό**. Αν έχεις δεύτερο κινητό (ή
θέλεις να δίνεις τις αναφορές σε κάποιον άλλο), αυτό το relay λύνει το θέμα:

```
[Κινητό ΜΕ Viber]  --ανεβάζει-->  [Cloudflare Worker]  --κατεβάζει-->  [Κινητό ΧΩΡΙΣ Viber]
   (Αποστολέας)                      (δωρεάν)                            (Παραλήπτης)
```

Ο παραλήπτης βλέπει τα ίδια σημάδια στον χάρτη **χωρίς να έχει καθόλου Viber**.

## Στήσιμο (μία φορά, ~10 λεπτά, δωρεάν, χωρίς κάρτα)

1. Φτιάξε δωρεάν λογαριασμό στο <https://dash.cloudflare.com/sign-up>.
2. **Workers & Pages** → **Create** → **Create Worker** → δώσ' του όνομα
   (π.χ. `diadromi-relay`) → **Deploy**.
3. Πάτα **Edit code**, σβήσε ό,τι υπάρχει, επικόλλησε όλο το `worker.js`
   από αυτόν τον φάκελο → **Deploy**.
4. **Storage & Databases** → **KV** → **Create a namespace**, όνομα π.χ. `ALERTS`.
5. Πίσω στον Worker → **Settings** → **Bindings** → **Add** → **KV namespace**:
   - Variable name: `ALERTS`  (ακριβώς έτσι)
   - KV namespace: διάλεξε αυτό που έφτιαξες
6. **Settings** → **Variables and Secrets** → **Add** → type **Secret**:
   - Name: `SHARED_KEY`
   - Value: ένα δικό σου μυστικό (π.χ. `to-diko-mou-kleidi-2026`)
7. Αντίγραψε το URL του Worker — κάτι σαν
   `https://diadromi-relay.<κάτι>.workers.dev`

## Ρύθμιση στα κινητά

Στην εφαρμογή: **🚨** → καρτέλα **💬 Ομάδες** → **🔗 Κοινή χρήση με άλλη συσκευή…**

| | Κινητό ΜΕ Viber | Κινητό ΧΩΡΙΣ Viber |
|---|---|---|
| Λειτουργία | **Αποστολέας** | **Παραλήπτης** |
| URL | το URL του Worker | το ίδιο URL |
| Κλειδί | το `SHARED_KEY` | το ίδιο `SHARED_KEY` |

Πάτα **Αποθήκευση & δοκιμή** και στα δύο — πρέπει να δεις `✅ Σύνδεση OK`.

## Όρια δωρεάν πλάνου (μπαίνεις άνετα μέσα)

| | Όριο/ημέρα | Τυπική χρήση |
|---|---|---|
| Εγγραφές KV (ανέβασμα) | 1.000 | ~30-100 (γράφει **μόνο** σε νέα αναφορά) |
| Αναγνώσεις KV (κατέβασμα) | 100.000 | ~1.400 ανά συσκευή (ανά ~60 δλ) |
| Αιτήματα Worker | 100.000 | ~1.500 |

## Ασφάλεια

- Χωρίς σωστό `SHARED_KEY` ο Worker απαντά **403** — κανείς δεν διαβάζει/γράφει.
- Κρατά το URL και το κλειδί ιδιωτικά (όποιος τα έχει, βλέπει τις αναφορές).
- Οι αναφορές διαγράφονται αυτόματα μετά από **6 ώρες** (κρατά έως 200).
- Αν το σταματήσεις, απλά σβήσε τον Worker — η εφαρμογή συνεχίζει κανονικά με
  Waze/TomTom.
